Your First LaTeX Document: Beginner Guide

Learn the minimum LaTeX needed to create a short article and see how it compiles to PDF.

1. Install the editor and TeX distribution

Download the appropriate build from GitHub releases and complete the setup. Takhti uses a local TeX installation for compilation; on Mac, setup can offer MacTeX when needed.

2. Start with a simple article

Create and save a new .tex file. Paste the following minimal example:

\documentclass{article}
\usepackage{amsmath}
\title{My First LaTeX Document}
\author{Your Name}
\begin{document}
\maketitle
\section{Introduction}
Hello, LaTeX!
\begin{equation}
E = mc^2
\end{equation}
\end{document}

3. Understand the structure

\documentclass{article} chooses a document type. The amsmath package supports mathematical typesetting. Everything between \begin{document} and \end{document} becomes document content.

4. Preview, then build the final PDF

Choose Takhti Live to follow incremental changes while editing. Before distributing the final document, run a full build: the live preview does not necessarily validate every page.

5. Fix common beginner problems

Check matching braces, correct environment names and closing commands. If TeX cannot find a package, confirm your TeX distribution is installed and contains the needed component. Read build messages when something does not compile.
