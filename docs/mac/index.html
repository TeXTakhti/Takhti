LaTeX Editor for Mac with Live PDF Preview

Takhti is a free LaTeX editor for Apple silicon Macs, combining local editing with incremental live PDF preview.

Compatibility: macOS 11 or later on Apple silicon. The current Mac build is a beta and is not Apple-notarized.

Write LaTeX and see the PDF beside your source

Use Takhti Live to follow updates as you edit equations, papers and lecture notes. You can also use manual or timed full builds before sharing a finished PDF.

Install Takhti on macOS

  1. Open Takhti's latest GitHub release and download the macOS DMG for Apple silicon.
  2. Open the DMG and drag Takhti into Applications.
  3. Launch the app and follow the first-run guided setup. Because the beta is not Apple-notarized, macOS may require you to explicitly allow it in system settings.
  4. Setup checks for the Takhti Live runtime and a full TeX distribution. If one is missing, it offers a download. MacTeX can require approximately 6.4 GB.
  5. Open or create a .tex document, then choose Takhti Live to see incremental PDF output.

Do I need MacTeX?

Yes, Takhti needs a suitable TeX installation for document compilation. It checks existing installations before offering the full MacTeX download. Keep enough free disk space and a reliable connection for first setup.

Where are my documents stored?

Editing and compilation occur locally, with no Takhti account required. Dependency downloads and release checks can still contact external services.
