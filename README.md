## Write with live output

- Incremental PDF preview beside your LaTeX source using Takhti Live.
- A pop-out preview for classroom projectors and second displays.
- Command suggestions and paired begin/end environments.
- Error highlighting and build logs.
- Autosave after successful live-preview updates.
- Project folders, document structure, templates and themes.
- Find and replace with Cmd+F on Mac and Ctrl+F on Linux/Windows.
- Manual and timed standard builds, plus configurable final build on close.

Live feedback is incremental; initial loading and complex documents may take longer. A full build validates the complete document separately.

## Install and start writing

**Mac:** open the DMG and run Install Takhti.pkg to install or update the app.

**Ubuntu:** install the DEB with your package installer, or run `sudo apt install ./Takhti-0.9.28-Ubuntu-amd64.deb`.

**Windows:** run the installer and follow the guided WSL setup. Administrator approval and a restart may be needed.

First-run setup detects existing components and offers missing dependencies. A full MacTeX or TeX Live installation can require several gigabytes. Downloads show progress and can resume after interruptions.

## Local writing

Editing and compilation happen on your computer. No Takhti account or manuscript upload is required. Dependency downloads and update checks use the internet; offline writing works once required packages are installed. Autosave after a live update does not guarantee that later pages are error-free.
